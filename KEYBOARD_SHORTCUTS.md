# EXPLORER — Keyboard Shortcuts

Quick-reference for in-exploration controls.

| Key | Action |
|-----|--------|
| W / A / S / D | Move forward / left / back / right |
| Mouse | Look around |
| Shift | Sprint |
| Ctrl | Crouch |
| Space | Jump |
| C | Toggle first-person / third-person camera |
| F | Toggle flashlight |
| E | Interact / inspect object |
| Tab | Explorer menu (pause menu) |
| P | Pause / Resume exploration |
| Mouse wheel | Zoom (third-person mode) |
| Esc | Exit Explorer (leave exploration) |
| Esc (menu open) | Close / back out of menu |
